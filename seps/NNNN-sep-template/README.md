To get started with this template:

- [ ] **Pick the owning org.** The org whose systems carry the work.

- [ ] **Copy this directory** to `seps/<owning-org>/NNNN-short-title`.

- [ ] **Open a PR** and link it from the tracking issue.
- [ ] **Merge early and iterate.** Start with the high-level sections; fill
  in details in follow-up PRs.

A merged SEP is not automatically approved. Anything marked `provisional`
is a working document subject to change. Mark open debates as:

```
<<[UNRESOLVED optional short context or usernames ]>>
Stuff that is being argued.
<<[/UNRESOLVED]>>
```

One SEP covers one enhancement for its whole lifecycle. Major changes to an
`implemented` SEP get a new SEP that `replaces` it.

Aim for tightly-scoped, single-topic PRs. Lines wrapped at ~80 columns so
reviews can cite specific passages.
